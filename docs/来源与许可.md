# 来源、许可证与改动声明

## 本仓库是什么

这是鹤竹子（竹子）基于自己两台电脑实测整理的配置方案、固定补丁、验收脚本和 Agent 操作说明。它**不是**下列任何上游项目的官方仓库，也不宣称与 Google、Apple、腾讯或上游作者有合作/认证关系。

新增说明文档采用 CC0-1.0。补丁中的代码仍受对应上游许可证约束；第三方程序按其各自许可证使用。
